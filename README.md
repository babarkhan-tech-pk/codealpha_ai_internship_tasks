# 🚀 CodeAlpha AI Internship — Project Tasks

This repository documents the artificial intelligence projects and tasks completed during my 1-month **Artificial Intelligence Internship** at **CodeAlpha**. Both projects were built and prototyped leveraging **vibe coding** methodologies to deliver fast, functional, and user-centric AI solutions.

---

## 📌 Projects Overview

### 1. 🌐 Translation App (`translation_app/`)

- **Description:** A language translation tool designed to convert text across multiple languages with high fluency and accuracy.
- **Methodology:** Built using rapid vibe coding techniques to deliver a clean user interface and reliable translation flow.
- **Key Highlights:** Multi-language support, responsive UI, and streamlined API integration.

### 2. 💬 AI FAQ Chatbot (`ai-chatbot-for-faqs/`)

- **Description:** An in-browser FAQ chatbot for AI topics powered by client-side Natural Language Processing (NLP) and cosine similarity matching.
- **Methodology:** Vibe coded using React 19, TypeScript, and Tailwind CSS v4.
- **Key Highlights:**
  - In-browser NLP text pipeline (tokenization, stop-word filtering, and suffix stemming).
  - Semantic cosine similarity scoring over term-frequency vectors without requiring an external backend[cite: 5].
  - 20 curated AI questions across 8 domains (Neural Networks, Transformers, Ethics, LLMs)[cite: 5].
